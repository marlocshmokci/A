# A — Ayurones AI

Локальное AI-приложение без OpenAI API.

## Состав проекта

- `app/` — FastAPI backend, SQLite память и база знаний, подключение к Ollama.
- `web/` — web-интерфейс.
- `training/` — обучение собственного Transformer с нуля.
- `android/` — нативное Android-приложение Ayurones.

## Сервер

1. Установите Python 3.11+ и Ollama.
2. Выполните: `ollama pull qwen3:8b`
3. Выполните: `pip install -r requirements.txt`
4. Запустите: `uvicorn app.main:app --host 0.0.0.0 --port 8000`
5. Откройте `http://localhost:8000`.

## Android

Откройте папку `android/` в Android Studio и запустите `app`.

Для Android Emulator API по умолчанию доступен через `http://10.0.2.2:8000`.

Для физического телефона укажите LAN-адрес компьютера в меню «Подключение», например `http://192.168.1.10:8000`. Телефон и сервер должны быть доступны друг другу по сети.

GitHub Actions собирает debug APK после push в `main`; файл публикуется как артефакт `Ayurones-debug-apk`.

## Обучение

Кнопка «Обучить» добавляет материалы в базу знаний. Runtime использует RAG, поэтому базу можно расширять без полного переобучения весов. Для обучения весов подготовлена папка `training`.

Большая языковая модель выполняется на сервере; APK является нативным клиентом и не содержит веса qwen3:8b.

OpenAI API не используется.
