# TrashHunter

Android-приложение для поиска потенциального мусора в выбранной папке.

## Возможности
- запрос доступа через системный выбор папки Android;
- рекурсивное сканирование файлов;
- поиск временных и служебных расширений;
- отдельная оценка APK, архивов и очень больших файлов;
- ручное подтверждение перед удалением;
- GitHub Actions для автоматической сборки debug APK.

## Безопасность
TrashHunter не требует скрытого доступа ко всему телефону. Анализ выполняется только в выбранной пользователем папке. Результаты классификации являются эвристической оценкой, а не гарантией того, что файл бесполезен.

## Сборка
Открой GitHub Actions → Build Android APK. После успешной сборки workflow прикрепит debug APK как artifact.
