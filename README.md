# Ayuron для Android

Приложение Android без Telegram: чат, три режима модели, анализ фото и генерация изображений. В приложении нет покупки подписок. Сервер ограничивает один installation ID 20 текстовыми и 8 медиа-запросами в сутки; счётчики сбрасываются в 00:00 UTC.

## APK

После успешной сборки APK публикуется в разделе Releases и доступен также в артефактах GitHub Actions.

## Безопасность API-ключа

Ключ Gemini отсутствует в Android-коде, APK, GitHub-файлах и настройках приложения. Приложение обращается к Cloudflare Worker, а Worker читает GEMINI_API_KEY из серверного секрета. Код APK можно декомпилировать, поэтому секреты нельзя надёжно хранить внутри клиента даже после обфускации.

Ключ, который ранее был вставлен прямо в код/сообщение, нужно отозвать и заменить. Удаление файлов из последнего коммита само по себе не отзывает ключ и не удаляет старые коммиты; workflow при первом запуске создаёт новый root-коммит без прежней истории ветки main.

## Развернуть сервер

Понадобятся аккаунт Cloudflare и Gemini API key.

1. Установи Node.js и Wrangler: npm install -g wrangler
2. Авторизуйся: wrangler login
3. Перейди в каталог worker и создай базу: wrangler d1 create ayuron-usage
4. В worker/wrangler.toml замени REPLACE_WITH_YOUR_D1_DATABASE_ID на ID из вывода команды.
5. Из каталога worker выполни wrangler secret put GEMINI_API_KEY и введи новый ключ в интерактивном терминале. Не вставляй ключ в репозиторий.
6. Из каталога worker выполни wrangler deploy.
7. Скопируй выданный HTTPS-адрес вида https://ayuron-api.<account>.workers.dev
8. Открой APK → ⚙ → вставь адрес.

Worker поддерживает /health, /usage, /chat, /analyze и /generate-image. D1 хранит счётчики квот на сервере. Идентификатор установки анонимный: очистка данных приложения может создать новый ID. Для публичного сервиса стоит добавить авторизацию и усиленную защиту от злоупотреблений.

## Режимы

- Ayuron 3 → gemini-3.5-flash-lite
- Ayurones → gemini-3.8-flash
- Ayurones 6 → gemini-4-argon
- Генерация изображений → gemini-3.1-flash-image

Это названия режимов приложения, не отдельные собственные модели. Доступ и тарификация определяются аккаунтом Gemini API. Бесплатность для пользователя приложения не гарантирует, что все вызовы API бесплатны для владельца серверного ключа.

## Сборка

GitHub Actions собирает установочный debug APK, сохраняет его как artifact и прикладывает к GitHub Release. Для долгосрочного публичного выпуска лучше настроить отдельную подпись release-сборки.
