# TikTok AUOI — TTAuOI

Version: v2.0.5

TTAuOI is being built as a TikTok mod layer inspired by existing modified TikTok clients.

## Mod menu

Intended location: Profile -> Privacy -> Mod.

Features: TTAuOI Telegram Channel; ISO region selector; minimum likes/views/publication-age filters; hide live streams, ads, feed photos and story photos; ten appearance colors; version v2.0.5.

## Real-mod architecture

The repository contains a standalone TTAuOI settings core and an integration specification. To produce an actual modified TikTok APK rather than a standalone settings application, a compatible TikTok APK must be supplied as the base input. The integration must adapt to that APK's exact package, resources and code structure.
