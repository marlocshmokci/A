# TTAuOI / TTA

This repository contains two separate directions:

- **TTAuOI v2.0.5** — the mod layer for the supplied TikTok base.
- **TTA standalone** — a new independent TikTok-style Android feed that imports TikTok video links and plays them through TikTok's official embedded player.

The standalone app does not contain the TikTok APK. It is intentionally independent and can evolve into its own feed, profiles, likes, comments, search and creator features.
