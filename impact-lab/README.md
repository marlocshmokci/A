# Impact Lab — физическая песочница

Мобильная веб-игра на HTML/CSS/JavaScript, без сборки и внешних библиотек.

## Запуск

Откройте GitHub Pages по пути `/A/impact-lab/` после включения Pages для ветки `main`. На телефоне откройте ссылку и выберите в меню браузера «Добавить на главный экран». Первое открытие требует интернета; Service Worker кэширует приложение для последующих запусков.

## Возможности

- 400 комбинаций геометрических форм и отделок, 350 комбинаций материалов и текстур.
- Сенсорное перемещение и поворот формы двумя пальцами.
- Панели можно поворачивать до 200°, задавать толщину в мм/см/мкм/м, делить и соединять в условный композит.
- Игровые столкновения с визуальной деформацией, частицами и условным индикатором тепла.
- Обычный режим и слоумо, сохранение сцены в браузере и отмена действий.

**Важно:** физика и индикаторы предназначены только для игровой визуализации. Это не инженерная модель и не средство прогнозирования реальных ударных свойств материалов.
