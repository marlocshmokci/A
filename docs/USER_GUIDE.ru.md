# Руководство Ayurones — Русский

В Ayurones много настроек и разделов. Эта инструкция специально намного проще интерфейса: выполняй только нужные пункты.

## 1. Первый запуск
1. Открой Ayurones.
2. Если Android попросит разрешение на уведомления, разреши его. VPN foreground-service может использовать постоянное уведомление.
3. Для обычного подключения не нужно включать все дополнительные фоновые функции.
4. Открой левое меню, чтобы увидеть все разделы.

## 2. Главный экран
- Start / Stop — запуск и остановка VPN-туннеля.
- Список серверов — импортированные серверы и подписки.
- Ping / статус — помогает выбрать доступный сервер.
- Трафик — активность при подключении.
- Левое меню — открывает все разделы.

## 3. Добавление сервера
Открой Servers. Можно импортировать URL подписки, proxy/share-ссылку или другой поддерживаемый источник.

Распространённые протоколы: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard и XHTTP.

## 4. Подключение
1. Выбери сервер.
2. Нажми Start.
3. Согласись с подтверждением VPN Android, если оно появится.
4. Дождись статуса подключения.
5. Для отключения нажми Stop.

## 5. Покупка сервера
Открой левое меню и выбери Buy a server / Купить сервер.

Можно указать страну, локацию, протокол, производительность, назначение, трафик в месяц, срок и дополнительные требования.

Нажми Открыть Telegram и заказать сервер. Ayurones откроет t.me/eppere с подготовленным текстом заявки. Telegram поддерживает username-ссылки с предварительно заполненным текстом: https://core.telegram.org/api/links

## 6. Маршрутизация
Открой Routing, чтобы определить, какой трафик идёт через какое направление.

Порядок:
1. Открой Routing.
2. Создай или измени направление.
3. Выбери сервер или группу.
4. Добавь правила.
5. Сохрани изменения или выйди из экрана, если текущий интерфейс использует автосохранение.

Если не знаешь, что менять, оставь значения по умолчанию.

## 7. DNS
Открой DNS Settings, чтобы менять DNS-серверы и DNS-правила. Меняй по одному параметру и проверяй подключение.

## 8. VPN Settings
VPN Settings содержит расширенные настройки туннеля. Для обычного использования большинство значений менять не нужно.

## 9. Speed Test
Speed Test позволяет сравнивать серверы. Результат зависит от твоей сети и текущей нагрузки.

## 10. Statistics
Statistics особенно полезен при работающем туннеле и показывает информацию о трафике и соединениях.

## 11. Config Editor
Config Editor — продвинутый редактор sing-box JSON. Не меняй raw-конфигурацию, если не понимаешь её структуру: ошибка может помешать запуску VPN.

## 12. App Settings
App Settings отвечает за настройки приложения: внешний вид и другие локальные параметры.

## 13. Debug
Если что-то не работает:
1. Повтори проблему один раз.
2. Открой Debug.
3. Посмотри свежую ошибку.
4. Определи, относится ли она к серверу, DNS, разрешениям или конфигурации.
5. Не меняй сразу много параметров.

## 14. Частые проблемы

### VPN не запускается
Проверь VPN-разрешение Android, выбранный сервер и попробуй другой сервер.

### После подключения пропал интернет
Останови VPN, попробуй другой сервер, затем проверь DNS и Routing.

### Большой ping
Запусти Speed Test и попробуй другую локацию. Повтори тест позже.

### Telegram не открывается
Проверь, установлен ли Telegram. Можно также открыть t.me/eppere в браузере.

## 15. Правило для новичка
Не меняй raw JSON, сложные DNS-правила, detour/цепочки и низкоуровневые параметры ядра без понимания их назначения.

Начни с одного сервера и стандартной конфигурации.
