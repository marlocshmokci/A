# Руководство Ayurones — Русский

Ayurones — локальный Android-мессенджер с упором на полноценную офлайн-работу.

## Чаты
На главном экране находятся сохранённые сообщения, тестовый чат и созданные контакты. Нажми «+», введи имя или username и открой новый чат.

История сообщений хранится на устройстве. Для сообщений доступны время отправки, ответы, редактирование и удаление, копирование и реакции. Черновик автоматически сохраняется.

Чаты можно закреплять, отключать звук, архивировать и очищать. Есть поиск по именам чатов и содержимому сообщений, а также счётчик непрочитанных сообщений.

## Файлы
Через кнопку «+» в чате можно выбрать реальный файл из устройства. Ayurones сохраняет URI файла, имя и размер, а по нажатию на вложение открывает его системным приложением.

## Контакты
Открой «Контакты» и добавь человека. Контакт сразу появляется в списке чатов. Длительное нажатие на чат открывает дополнительные действия.

## Профиль
В профиле можно установить фото, имя, username и описание. Доступны украшения, баллы и статистика активности.

## Украшения
Украшения можно покупать за баллы и надевать поверх фото профиля.

Текущие предметы:
- Искры — 80
- Корона — 180
- Ореол — 320
- Рамка — 450
- Кот — 600

Баллы:
- +5 за сообщение
- +10 за новое фото профиля
- +20 за ежедневный вход

## Звуки и медиатека
В приложении есть отдельная офлайн-медиатека из 10 встроенных звуков. Каждый звук реально находится внутри APK, его можно прослушать и выбрать как звук отправки сообщения. Настройку можно отключить.

## Резервная копия
В настройках доступны экспорт и импорт JSON-резервной копии. Переносится локальное состояние: контакты, чаты, профиль, настройки, баллы и другие сохранённые параметры.

## Test Server
В настройках можно указать адрес тестовой среды. По умолчанию используется http://127.0.0.1:8787.

Приложение Test Server поднимает локальный HTTP endpoint:
- /health — проверка доступности
- /status — состояние тестовой среды

## Windows
Windows-версия повторяет основную идею Ayurones: чаты, профиль, баллы и украшения.
