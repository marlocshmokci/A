# Руководство Ayurones — Русский

Ayurones — минималистичный мессенджер.

## Чаты
На главном экране находятся сохранённые сообщения, тестовый чат и созданные контакты. Нажми «+», введи имя или username и открой новый чат.

Сообщения сохраняются локально. Отправка сообщения начисляет 5 баллов.

## Контакты
Открой «Контакты» и добавь человека. Контакт сразу появляется в списке чатов.

## Профиль
В профиле можно выбрать фотографию с устройства и открыть раздел **Украшения**.

## Украшения
Украшения — единственное место, где интерфейс намеренно становится более выразительным. Можно покупать и надевать предметы поверх фото профиля.

Текущие предметы:
- Искры — 80
- Корона — 180
- Ореол — 320
- Рамка — 450
- Кот — 600

Баллы:
- +5 за сообщение
- +10 за новое фото профиля
- +20 за ежедневный вход

## Test Server
В настройках можно указать адрес тестовой среды. По умолчанию используется `http://127.0.0.1:8787`.

Приложение **Test Server** поднимает локальный HTTP endpoint:
- `/health` — проверка доступности
- `/status` — состояние тестовой среды

Test Server предназначен для проверки будущих обновлений и предоставляет неограниченные тестовые режимы.

## Windows
Windows-версия повторяет основную идею Ayurones: чаты, профиль, баллы и украшения.
