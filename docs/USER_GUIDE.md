# Ayurones Guide — English

Ayurones is a minimal messenger.

## Chats
The home screen contains saved messages, the test chat, and contacts you create. Press “+”, enter a name or username, and open the chat.

Messages are stored locally. Sending a message gives 5 points.

## Contacts
Use Contacts to create a person and open a conversation.

## Profile and Decorations
The profile lets you choose a photo from the device and open **Decorations**.

Decorations are deliberately more expressive than the rest of the UI. They sit on top of the profile photo.

Current items:
- Sparkles — 80
- Crown — 180
- Halo — 320
- Frame — 450
- Cat — 600

Points are earned from messages, changing the profile photo, and daily activity.

## Test Server
Settings can store a test-server address. The companion Test Server app can expose a local HTTP endpoint:
- `/health`
- `/status`

Test Server is the unrestricted environment for checking upcoming features.

## Windows
The Windows companion includes chats, profile, points and decorations.

## Капельки
Капельки remains a separate mini-game.
