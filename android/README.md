# Ayurones Android

Нативное Android-приложение для Ayurones. Это не WebView: интерфейс собран из Android Views, а сеть работает через обычный HTTPS/HTTP JSON API.

## Что уже работает

- чат с Ayurones;
- история диалогов;
- создание новых чатов;
- обучение серверной базы знаний из приложения;
- проверка состояния сервера и отображение активной модели;
- настройка адреса API;
- тёмный интерфейс;
- работа с Android 8.0+ (API 26+).

## Как запускать

Откройте папку `android/` в Android Studio и запустите конфигурацию `app`.

По умолчанию Android Emulator обращается к API по адресу:

`http://10.0.2.2:8000`

Для физического телефона задайте в меню «Подключение» адрес компьютера в локальной сети, например:

`http://192.168.1.10:8000`

Сервер Ayurones должен быть запущен отдельно:

1. установить зависимости корневого проекта;
2. запустить Ollama и модель `qwen3:8b`;
3. запустить FastAPI на порту 8000;
4. убедиться, что телефон и компьютер находятся в одной сети Wi‑Fi.

## APK

GitHub Actions автоматически собирает debug APK после каждого push в `main`. Готовый файл появляется в артефактах workflow с именем `Ayurones-debug-apk`.

Приложение является клиентом к локальному AI-серверу. Веса большой языковой модели не встраиваются в APK: так сохраняются разумный размер приложения и требования к устройству.
